Sales Performance Analysis Dashboard -Excel Project
Project Overview
This project presents a business sales performance analysis using Microsoft Excel.  
It helps to understand sales trends, profit distribution, and product performance through interactive visual dashboards.

Objective
To analyze sales data and extract meaningful insights that help in better business decision-making.

Key Analysis Performed
Total sales and profit calculation
Top-performing products
Sales trend analysis over time
Profit distribution by category
Regional sales performance

Dashboard Features
Interactive charts and graphs
Pivot tables for dynamic analysis
Slicers for easy filtering
Clean and user-friendly layout

Key Insights
Certain products contribute major revenue
Sales vary significantly across regions
Some categories show higher profitability
Seasonal trends are visible in sales data

Tools Used
Microsoft Excel
Pivot Tables
Charts & Graphs
Data Cleaning Techniques

Files Included
Excel Dashboard File (.xlsm / .xlsx)
